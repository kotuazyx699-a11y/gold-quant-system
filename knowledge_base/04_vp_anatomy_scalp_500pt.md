# 4 กายวิภาค Volume Profile (VPAnatomies_EA) สำหรับ Scalp 500 จุด ($5.00)
- 1. D-SHAPED (POC 34%-66%): ตลาดสมดุล ดัก BUY ที่แนวรับ VAL และดัก SELL ที่แนวต้าน VAH เป้าหมายเข้าหา POC
- 2. B-SHAPED (POC < 34%): โวลุ่มกองโซนล่าง เปิด SELL เมื่อโมเมนตัมขาลงและราคากดใต้ POC หรือเปิด BUY เมื่อเบรกทะลุ VAH ขึ้นไป
- 3. P-SHAPED (POC > 66%): โวลุ่มกองโซนบน เปิด BUY ตามแนวโน้มเมื่อราคายืนเหนือ/ย่อรับที่ POC/VAL และเปิด SELL หากหลุดกรอบล่าง VAL
- 4. DOUBLE ZONE (2nd Peak >= 60% ของ POC + มี Valley คั่น): ดัก BUY ที่ Lower Peak และดัก SELL ที่ Upper Peak
- ระยะ Scalp มาตรฐาน: SL = $5.00 (500 จุด), เลื่อนบังทุน BE เมื่อบวก +$2.50 (+250 จุด), TP = $5.00 - $6.50 (500 - 650 จุด)
